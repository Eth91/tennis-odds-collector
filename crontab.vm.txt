# CRONTABS FOR BOTH ORACLE BOXES — documentation, not a deployed file.
#
# WHY THIS IS IN THE REPO. The crontabs are VM-LOCAL state. They are not in git, they are not in
# any systemd unit, and nothing recreates them. A box rebuild, a `crontab -r`, or a fresh Oracle
# instance loses every line below with no error and no gap in any log — the loops keep running and
# only the *scheduled* work silently stops. That is the same shape as every other failure found on
# 2026-08-02: the thing that stopped was the thing nothing was watching.
#
# It nearly happened during the 32 GB re-clone: the crontab was cleared to keep cron from racing
# the swap and only restored from a hand-made backup in /tmp. Restore with:
#     grep -v '^#' crontab.vm.txt | crontab -        # on the MAIN VM only
# worker-2's entries are listed as comments at the bottom and must be installed there, not here.
#
# Paths are absolute on purpose: cron's PATH is not a login shell's.

# ── MAIN VM (wnba-loop-vm, 155.248.217.149) ────────────────────────────────────────────────────
# daily self-check a few hours before tip; silent when healthy, ntfy-URGENT on a silent failure
0 19 * * * cd /home/ubuntu/tennis-odds-collector && /usr/bin/python3 wnba_selfcheck.py >> /tmp/wnba_selfcheck.log 2>&1

# the golf archive pass + the PGA meters. Note pga_e3 and pga_grade run with `;` not `&&`, so a
# failed golf_collect cannot suppress pricing or grading.
*/30 * * * * cd /home/ubuntu/tennis-odds-collector && /usr/bin/python3 golf_collect.py >> golf_collect.log 2>&1 && /usr/bin/python3 pga_e1.py >> pga_e1.log 2>&1; /usr/bin/python3 pga_e3.py >> pga_e1.log 2>&1; /usr/bin/python3 pga_grade.py >> pga_e1.log 2>&1

# DENSE GOLF PASS (added 2026-08-02). The price that decides whether a golf market was soft is the
# LAST one before that player tees, and at 30-minute spacing that price is up to 30 minutes stale —
# mostly sampling error. --only-if-tee-within exits before any HTTP unless a tee lands in the next
# 75 minutes, so this costs nothing for the ~22 hours a day with no imminent wave.
*/5 * * * * cd /home/ubuntu/tennis-odds-collector && /usr/bin/python3 golf_collect.py --only-if-tee-within 75 >> golf_collect.log 2>&1
